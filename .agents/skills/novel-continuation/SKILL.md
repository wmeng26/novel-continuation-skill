# 小说续写

续写任何小说的操作流程：吃透原文 → 需要时联网查证 → 内部规划情节 → 落笔 → 自检。

核心原则：**续写的第一质量标准是"像不像原文"**——文风、人物、世界观三者缺一不可，情节精彩排在第二位。读者读到续写第一段的反应应该是"这就是同一个人写的"。

## 第一步：建立设定档案（必做）

动笔前，把原文中能提炼的信息整理成一份内部设定档案。逐项提取：

- **视角与人称**：第一/第三人称？限制视角还是全知？
- **文风指纹**：平均句长（短句急促还是长句绵密）、标点习惯（破折号/省略号/感叹号频率）、修辞密度（比喻多不多、什么类型）、段落长短、对话与叙述比例。
- **人物**：出场人物的姓名与称呼、说话方式（口癖、句式、礼貌程度）、当前动机、能力边界（会什么/不会什么）、彼此关系与关系温度。
- **时间线**：故事内现在是什么时间点、节奏快慢。
- **世界观规则**：时代背景、科技/魔法/武功体系、社会规则、专有名词表。
- **伏笔与未闭合线索**：埋了没回收的钩子、出场了没发挥的人物、没解的谜。
- **最后一场戏的悬置点**：原文停在哪里？人物最后一句话/动作/情绪是什么？续写必须从这一拍的"下一拍"开始，不能跳。

若用户以文件路径提供原文（.txt/.md 等），先读文件再提取。原文极长（几万字以上）时，至少精读：开头一章、最后一章、用户指定的范围，并全篇扫一遍人名与专有名词。

### 设定档案示例

原文片段：
> 陈默把烟按灭在罐头底上，没看林小满："东西你拿回去。我不查。"
> 林小满站在门边没动。楼道的声控灯灭了，她也没跺脚。

档案（节选）：
- 视角：第三人称，镜头贴着两人但不进内心，情绪全靠动作外化
- 文风：短句，零比喻，对话无引导词，情绪藏在动作里（按烟、不跺脚）
- 人物：陈默——嘴上拒绝但"我不查"留了余地，句短而硬；林小满——沉默执拗，用"不动"表态
- 悬置点：灯灭了，两人都没动 → 续写第一句必须还在这扇门口，从下一个动作写起

## 第二步：联网查证（按需）

以下三种情况先查再写，用 WebSearch 检索、WebFetch 读取页面：

1. **知名作品续写/同人**：核对人物设定、时间线、名词译名、已发生情节。需要一段原著文字作起手片段时，用 references/web-research-guide.md 中的**短语接龙法**。网络资料常有错——同人 wiki < 百科 < 原文文本，冲突时以原文为准。
2. **题材专业知识**：历史年代（官制、物价、称谓）、行业细节（医学急救、法律程序、航海操作）等，查证后再写，避免"想当然"。
3. **作者风格研究**：用户要求"模仿某作者"时，搜其代表段落与访谈，总结文风指纹（句长、用词、节奏），不照抄原文句子。

检索技巧与 GitHub 写作资源用法见 references/web-research-guide.md。查证结果并入设定档案。注意：只借设定事实与技法框架，**不照抄**任何来源的成段文字。

## 第三步：续写规划（内部完成，不必展示）

1. 确定本段续写要完成的 3–6 个情节节拍（beat），写成一行一个的内部提纲。
2. 确定结尾钩子：停在哪个新悬念或新信息上。
3. 用户给了方向就严格照办；没给方向，选悬置点最自然的下一拍，不要强行加新冲突。
4. 字数：用户指定了就照办；没指定，默认 1500–3000 字，网文按章（2000–4000 字）。

## 第四步：落笔

- **从悬置点的下一拍写起**：第一段必须能与原文无缝拼接，人物位置、光线、时间、情绪都不许跳。
- 对话沿用人物口癖与称呼；叙述沿用原文的句长、标点与分段习惯。
- 该演的场面要演成"现在进行时"，不要缩写成总结（避免"接下来三天他们……"），除非原文本身就常这样写。
- 不引入原文世界观里不存在的能力、组织、名词；新设定要顺着已有规则自然生长。
- 网文向：每几百字一个信息点或小高潮，章末留钩子；文学向：允许留白，控制节奏。

## 第五步：自检（写完必做）

读 references/craft-checklist.md，逐项对照。其中五项最关键：

1. **拼接**：把原文最后一段和续写第一段连读，有没有跳拍、跳时间、跳情绪？
2. **文风**：随机抽三句续写混进原文，认得出来吗？
3. **人物**：每句台词符合设定档案里的动机与口癖吗？有没有 OOC？
4. **逻辑**：时间线、因果、世界观规则有没有自相矛盾？
5. **钩子**：结尾停在让读者想往下翻的地方了吗？

发现问题直接改掉再交付，交付的就是改完的版本，不要把"以下问题供参考"甩给用户。

## 输出格式

- 默认只输出续写正文本身，不加附加大段分析；正文开头可加一行"【续写】"作分隔。
- 用户明确要"带大纲/带分析"时，先给 3–6 行节拍提纲，再给正文。
- 用户说"继续"时，接着上一次续写往下写，同样走第三～五步。
