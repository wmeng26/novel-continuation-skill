# 续写自检清单

写完后逐项过。任何一项不过，改完再交付。

## 1. 拼接（最容易翻车）
- [ ] 续写第一句与原文最后一句之间：时间连续、地点连续、人物姿势/动作连续
- [ ] 原文最后一场戏的悬置点（没说完的话、没接的动作）被接住了，没有被跳过
- [ ] 情绪连续：上一段压抑，续写第一段就不能突然轻快，除非有明确转折事件

## 2. 文风指纹
- [ ] 句长分布与原文一致（原文多短句，就不要写长排比）
- [ ] 标点习惯一致：破折号、省略号、感叹号的使用频率
- [ ] 修辞密度一致：原文零比喻，就不要突然"月光像水银泻地"
- [ ] 引导词一致：原文对话不带"他愤怒地说"，续写也不要带
- [ ] 分段粒度一致：原文单句成段，续写也单句成段

## 3. 人物一致性（OOC 检查）
- [ ] 每句台词读出声，像不像这个人的口癖、语气、用词水平
- [ ] 行为符合已建立的动机；性格转变必须有原文里已有的诱因
- [ ] 能力边界：没学会飞的不能突然飞；没揭穿的身份不能突然揭穿
- [ ] 关系温度连续：上段还在冷战，这段就不能突然掏心窝子（除非节拍需要且给了理由）

## 4. 情节与逻辑
- [ ] 时间线不矛盾：昼夜、星期、季节、人物年龄
- [ ] 因果成立：每个新事件有原因，每个反应有刺激
- [ ] 世界观规则不破例：魔法代价、科技水平、社会规则
- [ ] 伏笔处理：没到回收时机的不强行回收；能自然推进的推进一点

## 5. 节奏与钩子
- [ ] 没有大段总结式缩写（"接下来的日子……"），该演的场面演了
- [ ] 每 500 字内至少一个信息增量：新事件、新信息或新情绪
- [ ] 结尾停在新钩子上：悬念、反转前夜、一句没说完的话
- [ ] 网文向：章末钩子足以让读者点开下一章

## 6. 常见续写翻车点（出现即改）
- 大段复述原文已知信息凑字数
- 上来就加速剧情，把三年的事一段写完
- 新角色/新势力喧宾夺主
- 现代词乱入古代背景（"OK""心理阴影面积"）
- 解释过多：把原文刻意留白的地方全解释了
- 对话变成信息播报（"你知道当年……"式背景倾倒）
