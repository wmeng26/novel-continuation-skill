# 联网查证指南

## 何时查

- **知名作品续写/同人**：需要核对原著人物设定、时间线、名词译名、已发生情节时。例：续写《哈利·波特》同人前，确认对应学年的人物关系与重大事件；续写历史同人前，确认真实年表。
- **题材专业知识**：正文将涉及具体专业细节时。例：急救流程、法律程序、舰船操作、民国物价、古代官制。查不到就绕开这个细节写，不要编。
- **作者风格研究**：用户要求"模仿某作者风格"时。查其代表段落与访谈，提炼文风指纹（句长、用词、节奏、母题），用分析结果指导写作。

## 怎么查

### 通用检索（WebSearch + WebFetch）
- 人物/设定核对：`《作品名》 人物设定`、`作品名 时间线 整理`、`作品名 结局 解析`
- 译名/名词：关键词后加"译名"或"名词解释"
- 题材知识：直接查事实本身，如"1937年上海 法币兑美元汇率"；优先权威来源（百科、期刊、官方文档），两个来源一致才落笔

### GitHub 上的写作资源
用 WebSearch 加 site 限定检索：
- `site:github.com 小说 写作 资源`
- `site:github.com 网文 写作 教程`
- `site:github.com creative writing guide`
- `site:github.com novel writing prompts`

也可直接浏览 GitHub Topic 页，如 `https://github.com/topics/novel-writing`、`https://github.com/topics/creative-writing`。

找到仓库后，用 WebFetch 抓取 README；raw 地址更快：`https://raw.githubusercontent.com/<user>/<repo>/main/README.md`（分支也可能是 master）。仓库内的子目录文件同样按 raw 地址逐个读。

常见可用资源类型：
- 写作技法框架：三幕结构、英雄之旅、Save the Cat 节拍表——用于规划第三步的节拍提纲
- 网文写作合集：节奏控制、爽点分布、钩子设计——用于网文向续写
- 开源小说/同话语料：只用于感受文风，不可抄袭
- 世界观构建模板、人物设定表：字段设计可参考，用于补充设定档案

### 查找知名小说原文片段：短语接龙法

续写知名小说时，常需要一小段原著文字作为"起手片段"（用来提取文风指纹、确定续写悬置点）。难点：正版站（QQ阅读、起点、七猫）全是 JS 渲染的应用壳，抓不到正文；盗版聚合站（笔趣阁类、和图书、99藏书网、飘天文学）多有 Cloudflare 防护，curl 与 WebFetch 均会 403。可靠做法是用搜索引擎摘要做**短语接龙**：

1. 先搜 `书名 章节 已知开头词`，从摘要中拿到第一段，如：`大主宰 第一章 北灵院 "烈日如炎"`。
2. 取已得片段**末尾的一小截连续文字**（10～20 字），加引号、附书名再搜，如 `"鼻息间的呼吸，呈现一种玄妙的节奏" 大主宰`。搜索引擎的摘要会把这句话之后的一两百字"接力"展示出来。
3. 重复第 2 步逐段接力，直到凑够所需长度、找到合适的悬置点。
4. **每段必须有两个独立站点的摘要逐字一致才可信**——不同站的索引快照互为校验，防止凭记忆拼凑或盗版站错字混入。

局限与纪律：
- 摘要窗口只有一两百字，接龙效率低，适合拿一两百字的起手片段，不要指望拉出整章。
- 接不上的地方**不要凭记忆补全**——换个悬置点重新接，或直接从已有片段的句末开续。
- 引用要克制：起手片段一两百字、注明出处即可，续写正文必须全部原创。

### 读取失败时

先用 5 秒连通性测试再动手，避免在不可抓的站点上反复浪费时间：

```bash
curl -s -o /dev/null -w "%{http_code} %{size_download}\n" -A "Mozilla/5.0" "<url>"
```

`000`=连不上；`200`=可抓；`403`=有防护（多为 Cloudflare），换工具也无解，直接绕开。

工具回退顺序与已知坑：
- **WebFetch**：遇到 `REDIRECT DETECTED` 就按提示换成重定向后的 URL 重发一次。
- **web_reader（mcp__web_reader__webReader）**：只接受纯 ASCII 的 URL，含中文（即使百分号编码）会报 "Please Enter the Correct URL Format"。
- **curl + 浏览器 UA**：老式静态站大多能过；返回内容只有十几 KB 且正文靠 JS 加载（应用壳页面），说明是全站 JS 渲染，放弃抓取。
- 全站 JS 渲染或被 Cloudflare 挡住时，改走 WebSearch 短语接龙，或找该站之外的转载快照。

## 使用纪律

- 可靠性排序：同人 wiki < 百科词条 < 原文文本。资料之间冲突时，以用户提供的原文为准。
- 只借**设定事实**和**技法框架**；原著文字仅可引用一两百字的起手片段并注明出处，续写正文必须全部原创。模仿文风靠分析（句长、用词、节奏），不靠复制。
- 写进正文的年代、数据等事实，至少两个独立来源一致；拿不准的细节宁可虚化处理。
